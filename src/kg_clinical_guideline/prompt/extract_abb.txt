Extract all medical abbreviations (acronyms, ABBR) and their expanded forms from this CPG only.
Where to look (priority order):
1) Dedicated “Abbreviations” section (if present).
2) Figure legends, table captions, footnotes.
3) Main text using first-definition patterns: “expanded form (ABBR)” or “ABBR (expanded form)”.
Rules:
- Output must be in **JSON only** (no prose).
- Keep original capitalization of abbreviations.
- Deduplicate identical abbr/full_text pairs, merge all `locations`.
- If one abbr has multiple expansions, create separate entries.
- Exclude units (mg/dL, mmHg), symbols (Na⁺), and generic shorthand (vs, i.e., e.g.).
- Include page numbers or figure/table reference when available.
- Do not invent expansions. If uncertain, omit.
